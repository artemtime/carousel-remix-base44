# Цифровые сотрудники · приложение для Base44

Полный исходный код студии: интерфейс, серверная логика, схемы данных, агент,
фоновые процессы и тесты. Это веб-версия для Base44, отдельная от
[исходного Telegram-бота](https://github.com/artemtime/carousel-remix-bot).

- **Разведчик** получает посты конкурентов через Apify и помогает отобрать удачные.
- **Автор** готовит сценарий, рисует карточки со своим героем и оформлением.
- **Публикатор** собирает утверждённые PNG и подпись для экспорта или Buffer.

## Начать установку

1. Открой [Base44](https://base44.pxf.io/c/7904530/2049275/25619?trafcat=lp) и создание нового приложения.
2. Скопируй целиком [готовый промпт](docs/BASE44_SETUP_PROMPT.txt) и отправь в обычный чат Base44.
3. Дождись ответа и добавь свой APIFY_TOKEN по [инструкции](docs/INSTALL_RU.md).

Ссылка на этот открытый репозиторий уже внутри промпта. Подключение GitHub,
авторизация в GitHub, fork и синхронизация для этой инструкции не нужны.

GitHub хранит код. Он не переносит в твою копию базу преподавателя, ключи,
аккаунты, файлы каруселей или подключённые сервисы. Приложению нужны ресурсы
и серверное окружение Base44; запуск одного интерфейса ещё не завершает установку.
Порядок установки через чистый учебный аккаунт пока не проверен целиком.

## Где находится код

| Папка | Содержимое |
|---|---|
| `src/routes/` | страницы, серверные маршруты |
| `src/lib/` | серверные действия, Apify, AI Gateway, очередь, сборка и проверка PNG, Buffer |
| `base44/entities/` | схемы данных и права доступа |
| `base44/agents/` | агент студии |
| `base44/workflows/` | фоновые процессы |
| `tests/` | проверки поведения приложения |

Apify подключается через серверный секрет **APIFY_TOKEN**.
По умолчанию используется **apify/instagram-scraper**.
Для необязательного Buffer нужен отдельный **BUFFER_API_KEY**.
Ключи задаются в своей копии через Secrets, а не в GitHub или чате.

## Проверка кода

```bash
npm ci
npm test
npm run lint
npm run build
```

Полноценная работа требует окружения Base44. Данные, вход, хранилище, AI Gateway
и секреты обслуживает платформа; её внутренний движок не является частью репозитория.
Приложение рассчитано на личную студию владельца с правами администратора.
Для группы учеников создаются отдельные подготовленные копии.

### Текстовые карусели без героя

В окне «Собрать карусель» выберите «Только текст · без героя». Для «Зеркала» и «Максимально близко» сохраняются текст и оформление исходника без иллюстраций. «Адаптация» и «Своя история» используют выбранный текстовый стиль. В «Моих стилях» кнопка «Текстовый стиль» создаёт фон, шрифт и цвета без портрета. Можно начать и со стандартным оформлением.

Рисование для этого формата не запускается. Отредактируйте текст, нажмите «Проверить карточки», просмотрите итоговые PNG и нажмите «Утвердить». Только после этого доступен готовый пакет. Слишком длинный текст выдаёт понятную ошибку, а не обрезается. Чтение исходников, написание текста и проверка PNG могут расходовать кредиты; генерация иллюстраций не вызывается.
