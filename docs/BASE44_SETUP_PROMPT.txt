Подготовь этот проект как мою рабочую копию «Контент-отдела» в Base44.
Исходный код: https://github.com/artemtime/carousel-remix-base44

Прочитай README.md, docs/INSTALL_RU.md и AGENTS.md. Используй весь код репозитория, включая серверную логику в src/ и ресурсы в base44/. Не создавай похожую пустую витрину вместо рабочего приложения.

Сохрани Разведчика, Автора, Мои стили, отдельный выбор героя, четыре режима карусели, типографику, очередь рисования, проверку готовых PNG и Публикатор.

1. Подключи приложение к МОЕМУ новому Base44-проекту. Создай его схемы данных, права доступа, агента и фоновые процессы из base44/. Не используй базу, app ID, ключи или подключённые каналы преподавателя.
2. Подключи серверные вызовы и AI Gateway Base44. Это приложение для одного владельца: сохрани вход и права администратора. Не делай таблицы публичными.
3. Подготовь секрет APIFY_TOKEN для поиска Instagram через apify/instagram-scraper. Покажи, где открыть Dashboard → Secrets; значение я введу сам в защищённое поле. Не проси отправить ключ в чат и не сохраняй его в коде.
4. Оставь ручной режим, фоновые задания и публикацию выключенными до настройки. Не запускай массовую разведку, платное рисование, Buffer или Telegram при установке.
5. Выполни тесты и сборку. Проверь, что открываются основные разделы, а данные относятся к моему приложению. Реальную разведку я затем запущу сам на одном аккаунте.

Если импорт через Base Code не предоставляет нужное окружение Base44, остановись и объясни, какой шаг переноса в новый Base44-проект нужен. Не заменяй серверные сервисы заглушками и не объявляй установку завершённой только по работающему экрану.
