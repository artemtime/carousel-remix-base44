# Цифровые сотрудники

Студия каруселей для Instagram, перенесённая с Telegram-бота
[carousel-remix-bot](https://github.com/artemtime/carousel-remix-bot) на Base44.
Три цифровых сотрудника работают по заданию редакции: вы выбираете самостоятельность каждого этапа.

| Сотрудник | Что делает |
| --- | --- |
| 🔎 **Разведчик** | по нику или ссылке достаёт последние посты конкурента и показывает карусели и рилсы, выстрелившие сильнее его обычного уровня (лайки, комментарии, во сколько раз выше нормы) |
| ✍️ **Автор** | снимает чужой визуальный стиль в JSON, придумывает вашего героя и паспорт к нему, пересказывает чужой текст вашими словами, собирает план слайдов, рисует кадры и сам проверяет брак «критиком» |
| 📤 **Публикатор** | подставляет ваш ник, кодовое слово и подарок, собирает альбом и текст поста |

## Что внутри

- **Мои стили** — пропорции, манера рисования, профиль подписи (шрифт из каталога 37 кириллических,
  оверлей / тёмная полоса / светлая полоса, цвет, акцент, CAPS, сжатие букв, тень, «уходить с лица»),
  паспорт героя, лист-референс, мир стиля и 📌 Правила, которые Автор соблюдает во всех следующих каруселях.
- **Рилсы** — расшифровка речи, разбор хука и «почему залетел», сценарий под вашу тему, карусель из того же рассказа.
- **Слайды** — картинку рисует нейросеть, **буквы рисует только код** (Canvas + Google Fonts с кириллицей):
  разметка `**жирный**`, `==акцент==`, `^^мелкий^^`, автоподбор размера, перенос строк, экспорт PNG 1080px.
  Правка текста в вебе перерисовывает слайд мгновенно и бесплатно.
- **Разведка по расписанию** — список авторов, пауза, «+ рилсы», до 3 хитов с автора, показанное не повторяется,
  недоступный аккаунт после трёх проверок уходит на паузу.

## Как рисуется кадр

В фоне карточки своего стиля собираются на сервере (JavaScript PNG): тот же алгоритм безопасных отступов измеряет реальные контуры букв выбранного кириллического шрифта. Сервер использует сохранённое положение подписи, без автоматического поиска свободного места и обрезки внешнего паспарту. Карточки с ручным `trim_footer` и точные режимы «Зеркало»/«Максимально близко» собираются в браузере. Финальная проверка блокирует брак, включая рамки. Версия движка хранится отдельно для каждой карточки; ранее утверждённые PNG сохраняются.

Оформление зависит от режима:
- **Зеркало:** персонаж, рисовка, цвета, шрифт и композиция оригинала.
- **Максимально близко:** оформление оригинала, но выбранный герой пользователя.
- **Адаптация:** смысл и контраст исходных сцен, полностью своя рисовка,
  палитра, пропорции и типографика выбранного стиля.
- **Своя история:** тема и хук исходника, новые сцены и текст в выбранном стиле.

В адаптации исходная картинка не передаётся художнику как образец. Её место
занимают сохранённые изображения выбранного стиля и паспорт/лист своего героя.
Проверка качества сравнивает результат с этим стилем и паспортом, допускает
самостоятельную композицию и отклоняет чужого персонажа или рисовку.

Текст накладывается кодом. В каждом полукадре действуют собственные безопасные отступы: код измеряет реальные буквы выбранного шрифта, переносит слова, проверяет ширину и высоту и удерживает всю подпись внутри кадра. Слишком длинный текст вызывает понятную ошибку вместо обрезки или нечитаемого уменьшения. Рисунок своего стиля заполняет края; уверенно обнаруженное внешнее светлое паспарту убирается при сборке, а внутренние пустые плашки считаются браком рисунка. Для отдельной пустой полосы под рисунком есть обратимый переключатель в каждом полукадре: он удаляет только распознанную полосу с явной границей и не заказывает новую картинку. В своём стиле используется полная сохранённая
типографика, включая шрифт, цвета, регистр, акценты и настройки роли слайда;
редактор, PNG и Buffer получают одну и ту же карточку. В точных режимах
используются блоки текста и подложки оригинала. Длинные подписи переносятся
по словам в границах исходной рамки; явные переносы сохраняются. Размер шрифта
подгоняется после переноса, чтобы подпись не сжималась в одну мелкую строку. Головы и руки целиком в кадре;
буквы и логотипы внутри сгенерированных иллюстраций запрещены.

Герой выбирается отдельно от стиля и сохраняется в карусели при создании.
Исходный разбор сохраняется независимо от последующих переключений режима.
Пропорции иллюстрации задаются генератору по геометрии конкретного кадра,
включая широкие верхнюю и нижнюю половинки. Используется ближайший поддерживаемый
формат через AI Gateway с выбранной моделью рисования. Положение рисунка
настраивается для каждого кадра во всех режимах: верх, центр или низ. Эта
настройка меняет только обрезку в редакторе, PNG и публикации, без новой генерации.
В адаптации разрозненные и дублирующиеся фрагменты исходной надписи
объединяются: каждый кадр получает одну законченную подпись на выбранном языке.
Старые стили с пропущенной палитрой восстанавливают её по своим образцам,
не перезаписывая выбранный пользователем шрифт или описание рисовки.

## Выбор модели рисования

В новой карусели и в Авторе доступны «Автоматически · Base44», «Gemini · Nano Banana 2.1» и «GPT Image 2 · OpenAI». Общая настройка задаёт модель для новых каруселей и листов героя; каждая карусель хранит свой выбор. GPT Image использует качество medium. Стоимость зависит от модели, а лимит рисунков считает запросы, а не деньги.

Очередь сохраняет выбранную модель при запуске: исправление кадра использует ту же модель, даже если общие настройки изменились. При ошибке сервиса очередь приостанавливается без переключения на другую модель. Выбор можно сменить после остановки рисования; уже готовые карточки сохраняются. Для их замены нажмите «перерисовать». Для каждого нового кадра сохраняется модель генерации; при автоматическом выборе имя остаётся неизвестным, если платформа его не сообщила. Текст и безопасные отступы по-прежнему рассчитываются кодом.

## Проверка и утверждение результата

После рисования карусель остаётся на проверке. В Авторе нажмите «Проверить карточки»:
приложение собирает PNG шириной 1080 с окончательными подписями, сохраняет их и проверяет
обрезку головы и причёски, края, читаемость, содержание текста, внешность и рисовку.
Затем просмотрите все карточки и нажмите «Утвердить». Недоступная или отрицательная
проверка блокирует утверждение. Принятый черновой рисунок сам по себе не является готовой карточкой.

Кнопка «Исправить замечания» меняет только отмеченную сцену или положение/размер её подписи, сохраняя удачные кадры, текст, шрифт и цвета. Максимум две попытки; неясная локализация и замечания к типографике точного оригинала требуют ручной правки. Исправление раскладки не заказывает новый рисунок.

Любое изменение рисунка, текста, подписи, положения кадра, шрифта, стиля или героя
отменяет прежнее утверждение по версии содержимого. Публикатор и Telegram получают
только утверждённые PNG и сохранённую подпись; текущие настройки призыва к действию
не дописываются заново. Отправка в Buffer означает очередь или расписание, а не публикацию.
После неопределённого ответа Buffer автоматический повтор запрещён: проверьте внешний пост.

Для точной внешности в редакторе стиля есть «Выбрать героя на образце».
Выделите одного персонажа с видимым лицом или маской. Выбранный портрет сохраняется
вместе с описанием и передаётся художнику. Описание не должно угадывать историческую личность.

Студия закрыта для пользователей без роли admin; серверные платные действия и данные
защищены отдельно от интерфейса. Очередь использует условную атомарную блокировку,
версию сцены и оформления и отбрасывает устаревшие ответы. Фоновое восстановление
продолжает только ранее запущенные задания, не перерисовывая уже принятые кадры.
Настраиваемый лимит изображений учитывает попытки до вызова модели, включая исправления;
это число запросов, а не денежный баланс. Счётчик начинается с внедрения этой версии.

Разведка хранит курсор полного прохода активных авторов. Недельное расписание использует
заданные день, час и часовой пояс; ноль часов допустим. Первый запуск расписания
только фиксирует исходную неделю. Telegram запускает очередь асинхронно; доступны
проверка состояния и пауза. Ручное утверждение выполняется в веб-редакторе; автоматическое — только по явно разрешённой политике редакции.

## Цифровая редакция

Главная «Сегодня» показывает решения, работу, готовые материалы, расписание, реальные подтверждённые публикации, лимиты и сообщения сотрудников. «Редакция» хранит аудиторию, продукт, цель, темы и исключения, голос автора, примеры формулировок, стиль, героя и модель. Эти ограничения получают новые планы.

- **Ручной:** каждый этап запускаете вы.
- **Редактор:** разведка и производство работают сами после утверждения идеи; готовую публикацию утверждаете вы.
- **Автопилот:** выбор идей, производство, ограниченные исправления и утверждение по образцу. Каждый этап можно переключить отдельно. Публикация по умолчанию выключена даже в этом режиме.

Для автоутверждения создайте пробную карточку, просмотрите её и подтвердите образец. Затем отдельно разрешите автоматическое утверждение. Смена стиля, героя или модели требует нового подтверждённого образца. Отрицательная или недоступная проверка всегда блокирует утверждение. Смена задания останавливает старые автоматические задания для ручного решения.

Редакция отбирает уже собранные карусели только активных авторов Разведчика, без повторов, исключённых фраз и превышения недельного количества. Автоматическая разведка дополнительно использует недельное расписание в обычных настройках. Ручная кнопка «Подготовить неделю» берёт текущую библиотеку источников. Это не новый алгоритм конкурентного ранжирования.

Фоновый workflow выполняет ограниченные шаги каждые пять минут. «Пауза редакции» блокирует новые платные запросы и отправки. Существующие внешние публикации в расписании останавливаются в Buffer. Лимиты запросов за местный день и неделю резервируются атомарно до вызова сервиса, включая проверки и исправления; это не денежный баланс. Ежедневный отчёт появляется внутри приложения, без внешних уведомлений.

Публикация включается отдельным этапом после выбора подключённого Instagram-канала Buffer, дней, часа и часового пояса. После отправки сохраняется ID; приложение сверяет статус раз в 15 минут и вручную по кнопке. Только `sent` с временем, внешней ссылкой и автоматической отправкой становится «Опубликовано». Неизвестный результат не пересылается повторно: найдите пост в Buffer и сверяйте его ID, канал, точную подпись и порядок изображений через Публикатор. Проверки разработки не отправляют реальные посты.

## Установка своей копии

1. Разверните приложение в своём аккаунте Base44 (этот код) и опубликуйте.
2. **Ключ Apify.** Зарегистрируйтесь на [apify.com](https://apify.com), возьмите токен в
   *Settings → Integrations → API token*. В приложении откройте **Dashboard → Secrets** и добавьте
   `APIFY_TOKEN`. Необязательно: `APIFY_INSTAGRAM_ACTOR`, если хотите другой актор скрейпинга
   (по умолчанию `apify/instagram-scraper`).
3. **Заполните настройки**: ник в Instagram, кодовое слово, подарок, тема блога, часовой пояс.
4. **Снимите первый стиль**: «Мои стили» → «Новый стиль» → ник автора, чей вид нравится → выбрать карусель →
   поправить профиль подписи → придумать героя → сохранить → собрать лист героя.
5. **Telegram.** В Base44 откройте *Dashboard → Agents → Edit Agent → Telegram → Connect Telegram Bot*
   и следуйте подсказкам: создаётся бот и подключается к агенту приложения. Дальше пишите боту как человеку —
   «разведай @ник», «сделай карусель из этого поста», «покажи мои стили».
6. **Недельная разведка.** Добавьте авторов в список на странице «Разведчик». Расписание задаётся в
   настройках; кнопка «Проверить всех сейчас» запускает проверку вручную.

## Публикация

Первая версия публикует вручную: «Публикатор» → скачать все PNG по порядку → скопировать подпись →
загрузить каруселью в Instagram. Автопостинг через Meta Graph API (бизнес-аккаунт IG + страница Facebook +
токен) — следующий этап.

## Стек

TanStack Start (React 19) на Base44, Tailwind, Canvas-рендер слайдов, Apify для сбора постов,
встроенные генерация изображений и распознавание речи платформы.
## Работа с сохранённым кодом

Исходники: `src/`. Схемы данных, правила доступа, агент и расписания: `base44/`. Проверки: `tests/`.

```bash
npm ci
npm test
npm run lint
npm run build
```

Приложение использует окружение Base44: авторизацию, хранилище данных, AI Gateway и секреты. Для полноценной работы запускайте его через Base44; обычный локальный сервер без подключения к платформе не заменяет эти сервисы. Секреты задаются через Dashboard → Secrets. Архив исходников не содержит значений секретов, базы каруселей и пользовательских файлов.
