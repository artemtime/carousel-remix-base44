# Установка своей копии «Цифровых сотрудников»

## 1. Открой официальный Base44

Переходи по [этой ссылке — base44.com](https://base44.pxf.io/c/7904530/2049275/25619?trafcat=lp), затем нажми
**Start building**. Рабочий кабинет находится на **app.base44.com**.
Не попадайся на мошеннические ссылки: проверь адрес перед входом и оплатой.

Войди в свой аккаунт. Для начала регистрации оплачивать тариф не нужно.
Перед установкой проверь доступность нужных функций в своём кабинете:
цены и возможности тарифов могут меняться.

## 2. Вставь один готовый промпт

Код: https://github.com/artemtime/carousel-remix-base44

1. Скопируй целиком [готовый промпт](BASE44_SETUP_PROMPT.txt).
2. Открой создание нового приложения в Base44 и вставь промпт в обычный чат.
3. Отправь и дождись ответа. Ссылка на открытый код уже включена в промпт.

Подключать GitHub, регистрироваться в нём или делать копию репозитория не нужно.
Задание для Base44 — самостоятельно прочитать открытый код и перенести приложение
в твой проект: экраны, серверные действия, данные и генерацию.
Публичный архив исходников также указан в промпте; для его чтения вход не требуется.

Если Base44 сообщил, что не смог прочитать код или выполнить часть установки,
сначала разберись с этим сообщением. Наличие похожих экранов ещё не подтверждает
работу поиска и рисования. Проверка установки в чистый учебный аккаунт
этим способом пока не завершена; гарантии работы на каждом тарифе нет.

## 3. Подключи Apify

Apify нужен Разведчику, чтобы получать публичные посты, изображения, подписи
и показатели конкурентов. Ничего устанавливать на компьютер не нужно.

1. Открой [Apify](https://apify.com/) и регистрацию **Get started / Sign up**.
2. Зарегистрируйся своей почтой или через Google. При регистрации по почте
   подтверди адрес из письма.
3. В кабинете открой **Settings → API & Integrations**.
4. Создай отдельный токен через **Create a new token**, назови его, например,
   **Цифровые сотрудники** и скопируй кнопкой рядом с ним. Не отправляй значение в чат.
5. В СВОЁМ приложении Base44 открой **Dashboard → Secrets**, добавь секрет
   с точным именем **APIFY_TOKEN** и вставь скопированное значение. Сохрани.

В коде уже выбран [Instagram Scraper от Apify](https://apify.com/apify/instagram-scraper).
Его не нужно скачивать, переписывать или отдельно запускать при каждом поиске:
приложение обращается к нему само. Используй сбор публичных материалов.

Список запусков и расход видны в Apify. Перед первым поиском проверь баланс
и условия своего тарифа; бесплатный остаток не означает безлимитную работу.

## 4. Сделай одну проверку

Открой Разведчика в своей копии. Вставь один публичный ник и нажми **Разведка**.
Результат — реальные посты и показатели. Если материала нет, сначала прочитай ошибку.

- **Не задан APIFY_TOKEN:** проверь название секрета и сохранение в своём приложении.
- **401:** перепроверь ключ и срок его действия.
- **Недостаточно прав:** проверь права отдельного токена на запуск актора и чтение результата.
- **Лимит или оплата:** проверь запуск и баланс в Apify, не повторяй массовый поиск.
- **Посты не найдены:** попробуй один заведомо открытый профиль.

Рисование — следующий этап. Оно использует AI-возможности и кредиты твоего Base44-проекта.
Для ручного экспорта картинок Buffer и Telegram не обязательны.

## Что считается завершённой установкой

Открываются разделы студии; данные принадлежат твоему Base44-проекту;
ключ хранится в Secrets; один поиск возвращает настоящий материал.
Фоновые задания и автопубликация ещё выключены.

Копия кода проверена отдельно от установки в чистый аккаунт ученика.
Наличие README и промпта само по себе не подтверждает, что такая установка
уже выполнена и проверена на каждом тарифе.

## Текст без героя

Проверьте наличие «Текстовый стиль» в библиотеке и «Только текст · без героя» при создании карусели. Этот формат не требует портрета, листа героя или модели рисования. Проверьте импорт одного текстового поста, его редактирование, сборку, проверку и утверждение PNG. Отсутствие кнопки рисования здесь ожидаемо. Наличие этих кнопок само по себе не заменяет проверку работы своей копии.
